Infinite Engine on Mac
======================

These scripts set up Infinite Engine on a Mac (Apple Silicon or Intel) so
you can build and run it without typing commands.

What's in this folder (docs/setup/macOS):

  install-mac.command   Installs everything you need. Run it once.
  compile-mac.command   Builds the engine and launches it.
  how-to-use.txt        This file.

There's also .vscode/tasks.json, which adds build buttons to VS Code. It's
optional.


Before you start
----------------

- Clone the repo and switch to the dev branch.
- You need an internet connection and around 5-10 GB of free space.
- Keep this folder where it is. The scripts look for Project.xml by going
  up from their own location, so they only work inside the project.


Step 1: install-mac.command (first time only)
---------------------------------------------

Double-click it and let it run. It installs Homebrew, Haxe and the
project's libraries, and sets up Lime. It takes a few minutes, so don't
close the window. When it says it's done, press any key.

A few things that can happen along the way:

- macOS won't open it: right-click the file, choose Open, then Open again.
- It asks you to install Apple's command line tools: accept, wait for it to
  finish, then run the script again.
- It asks for your Mac password: that's for Homebrew.

If it gets interrupted, just run it again. It's safe to repeat.


Step 2: compile-mac.command (whenever you want to test)
-------------------------------------------------------

Double-click it to build the engine in debug mode and open it. The first
build takes several minutes. After that it's a lot faster. When you close
the game, press any key to close the window.

It also includes a workaround for the 'SDK "macosx26" cannot be located'
error.

For a clean build, delete the "export" folder and run it again.


Using VS Code (optional)
------------------------

1. Open the project folder in VS Code.
2. Install the recommended extensions (Haxe and Lime) if it asks.
3. Press Cmd + Shift + B to build and run.

Other tasks are under Terminal > Run Task:
"Install Dependencies (macOS)" and "Clean Build".


If something goes wrong
-----------------------

"Permission denied"
  Open Terminal in the project folder and run:
    chmod +x docs/setup/macOS/*.command
  If it's still blocked:
    xattr -dr com.apple.quarantine docs/setup/macOS

"Run install-mac.command first"
  Something from the install is missing. Run install-mac.command and wait
  for it to finish.

Build error
  The logs are saved here (open them with the Console app or any text
  editor):
    ~/Library/Logs/InfiniteEngine-install.log
    ~/Library/Logs/InfiniteEngine-build.log
  Send the last 20 lines or so to whoever is helping you.

Starting over
  Delete "export" (the build) or ".haxelib" (the project libraries) and
  run the matching script again.


Differences from Windows
------------------------

- The debug console (F2) is Windows only. On Mac, the messages show up in
  the compile-mac.command window.
- Dark mode and rounded window corners are Windows features, so you won't
  see them on Mac.
- Mods that use WindowsAPI or WindowsGDI won't work on Mac.
